# 🧪 Fabiansyah Putra — Persona 3 Portfolio

Portfolio pribadi bertema **Persona 3** (Atlus) — UI cyber-industrial dengan panel glassmorphism, bento-grid, video background, dan transisi halaman bergaya game.

## 🛠️ Tech Stack

- **React 19** + **Vite 8**
- **React Router DOM v7** — SPA routing
- **Framer Motion v12** — transisi & animasi
- **Vanilla CSS3** — custom properties, glassmorphism, tanpa framework CSS
- **Express 5** — serve build production + SPA fallback

## 🚀 Halaman

| Route | Isi |
|---|---|
| `/` | Menu utama ala Persona 3 dengan video intro + loop |
| `/about` | Profil, bento-grid, stack |
| `/resume` | Ringkasan repo GitHub, skills, projects |
| `/socials` | Kartu GitHub / LinkedIn / Instagram |
| `/sideproj` | Repo GitHub live via GitHub API + navigasi keyboard |

Navigasi keyboard: **↑ ↓** pilih item, **Enter** buka, **Esc/←** kembali.

## ⚙️ Menjalankan

```bash
npm install
npm run dev      # dev server → http://localhost:5173
```

Production:

```bash
npm run build
npm start        # Express → http://localhost:3000
```

Windows: double-click `run_app.bat` (auto cek Node + install + jalanin dev).
